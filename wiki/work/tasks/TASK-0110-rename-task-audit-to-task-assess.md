# TASK-0110 — Rename task-audit to task-assess

blocks::[[TASK-0111]]

> **Roadmap**: [ROADMAP-0014](../roadmaps/ROADMAP-0014-wiki-skill-deduplication-fixes.md) Phase 4 — Family & Action Vocabulary Standardization (first item; the Phase 4 renames run as a sequential chain because they overlap on shared files). **Decisions**: recorded in ROADMAP-0014 Notes (Q&A 2026-09-19) — Note 4: old skill names are hard-renamed with no redirect stubs.

## Objective

Hard-rename the `task-audit` skill to `task-assess` so the `tasks` family shares the common `create`/`assess` action pair used by `roadmap-assess` and `bug-assess`. The skill directory moves with `git mv`, its `name:` frontmatter / heading / description / self-references change, and every live reference across the repo is updated. No redirect stub is left behind. A residue-sweep test proves no live `task-audit` reference survives outside historical records.

## Approach

- **Hard rename, no alias.** `git mv lib/skills/task-audit lib/skills/task-assess` (the directory is tracked; `SKILL.md` currently carries uncommitted modifications, which `git mv` preserves). The behaviour, flags (`--json`), steps and output file (`wiki/work/tasks/dependency-graph.md`) are unchanged — only the name and the words "audit"/"Audit" that name the skill change. Wording that describes what the skill *does* ("verify implementation completeness") stays.
- **Out of scope by instruction.** Do NOT touch the installed copy `~/.claude/skills/task-audit/` and do NOT run `install-global.sh` — TASK-0122 (installer prune) removes stale installed skills later. Do NOT edit `wiki/log.md` (append-only) or anything under `raw/` (immutable).
- **Historical records are not rewritten.** Files that record work done under the old name keep it: `wiki/log.md` and `wiki/log-*.md`, `raw/**`, every `archive/` directory, `wiki/hot.md` (regenerated by the hot-cache refresh, not by hand), and the point-in-time work items under `wiki/work/**` (task, UAT, roadmap and decision files — e.g. TASK-0094/0095/0097/0099, UAT-0094/0097, and ROADMAP-0014's own Phase 4 wording, which names the rename it is tracking). Live pages — skills, scripts, tests, README/CLAUDE.md, `lib/skills/README.md`, `.serena/memories/`, and `wiki/knowledge/**` plus `wiki/index.md` — are updated.
- **Tests pin the old name and must be updated**, not deleted. Test *file* names (`task-typed-links.test.js`, `task-dependency-single-source.test.js`, `task-dependency-fields-content.test.js`, `archive-work-item.test.js`) describe their subject and stay; their `task-audit` paths, constants (`TASK_AUDIT` → `TASK_ASSESS`), test titles and assertion messages change.
- **Residue sweep.** A new hermetic `node:test` file walks the live tree and fails on any surviving `task-audit` / `task_audit` / `Task Audit` (case-insensitive) outside the historical allowlist above.
